# Canvas-first Graph Editor and output-first Live (#109)

The changes reuse the extension HTML/CSS/JS and graph runtime. No graph schema,
model, port contract, capture lifecycle or persistence changes were made.

## Interaction coverage

- The default editor is the canvas, Save, concise draft/session state, Add Node,
  Graph actions, Help, zoom and Fit graph. The permanent introductory text,
  instruction paragraph, translation fieldset and TranslateGemma footer are gone.
- Add Node opens a searchable native list grouped into sources/inputs,
  processors, constants/utilities and outputs. Category filters, empty results,
  Enter to add, focus into editable settings and Escape/Close are tested.
- Settings appear only for the selected node. Help/contracts use a closed
  disclosure. Removal is contextual to the inspector, keeping cards compact
  while preserving 44-pixel heading/port targets at 100% zoom. Long camel-case
  port labels wrap at words; the named contracts and accessible port IDs remain
  unchanged. The inspector stacks below the canvas in narrow windows.
- Load/reset/validate are available through Graph actions. Load/reset confirm
  before discarding unsaved changes. The optional Translation preset explicitly
  describes its bulk effect and lists the actual translator directions, including
  mixed-direction graphs. Both concrete OPUS-MT nodes remain discoverable.
- Existing MV3 tests operate these disclosures before testing click/drag/keyboard
  connections, occupied-input replacement, on-canvas wire selection/Disconnect,
  fan-out, validation, Save, immutable active sessions, external-save conflicts,
  migration, reload/restart and translation/TTS/model recovery.
- Live puts graph-driven text/audio outputs before compact recording controls.
  It preserves zero/one/multiple display graphs. Replace-only sinks say Current
  value; sinks with append say Preview, with a dashed border and separate muted
  surface. The committed list retains DOM nodes, selection, scroll, whitespace,
  repeated/empty final items and safe plain text rendering. Labels are excluded
  from copied/output text. Copy, Stop/finalize, Cancel, generated audio/WAV and
  optional target controls retain the production lifecycle.
- Deterministic Chromium and WebKit tests cover the actual extension modules and
  styles without capture APIs. Packaged Chrome MV3 tests add native keyboard,
  touch, window narrowing, focus restoration, status/error roles, mixed model
  graphs and production session behavior. Focus, reduced motion, modal Help,
  390/700-pixel layouts and a native narrow palette are checked before merge.
