See cosyvoice3-LICENSE.txt for the Apache license.

Modified graph: this repository exposes the conversion's 22 flow attention
masks as a streaming_mask input. Weights are unchanged. The Worker recomputes
bounded chunk-masked prefixes, retains accepted mel, and withholds vocoder right
context before transferring PCM. HiFT's three integer nearest upsamplers are
modified to reshape/tile operations to avoid WebGPU Resize uint32 overflow.
This is an independently implemented runtime;
Quick Inference's PolyForm Noncommercial runtime and patched ORT are not included.

Default reference voice: LibriTTS-R, Koizumi et al. (2023), OpenSLR 141,
speaker 4446, utterance 4446_2275_000002_000009, via mythicinfinity/libritts_r.
https://www.openslr.org/141/
https://huggingface.co/datasets/mythicinfinity/libritts_r
voice_default.json contains derived features, licensed CC BY 4.0:
https://creativecommons.org/licenses/by/4.0/
No original audio is redistributed. Attribution is required when redistributing
these features. The model conversion and streaming synthesis modify the source.

Shared packaged runtime: stock onnxruntime-web 1.31.1 (MIT), Transformers.js
3.8.1 Qwen2 tokenizer (Apache-2.0). See qwen3-tts.txt, onnxruntime-tts.txt,
transformers-tts-LICENSE.txt and the packaged ORT notices.
Exact URLs, sizes, source digests and graph transformation digest:
docs/cosyvoice3-artifacts.json. English/Japanese only are exposed; other
languages, voice cloning, CPU inference and mobile are unqualified.
