TranslateGemma 4B Translation

Google TranslateGemma 4B text-only ONNX, q4, local WebGPU execution. Run downloads about 3.112 GB of model assets from Hugging Face unless cached. Requires a supported GPU and several GB of available memory. The upstream Gemma Terms and Prohibited Use Policy apply.

Text stays on this device. Try a short snippet; generation is capped at 256 output tokens. Repeated Runs reuse one loaded model, including language changes. Cancel releases the Worker immediately.

Unconnected defaults are Japanese (ja) → English (en), with no automatic detection. Enter template language codes, for example en → ja or fr → en. Unsupported explicit codes report an error. The graph uses optional TEXT ports supplied by Text Nodes for these values.
