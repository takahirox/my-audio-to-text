Kokoro 82M Text-to-Speech

Generate locally with Kokoro 82M v1.0 (q8 WASM). First Run downloads about 93 MB of model/voice assets plus the runtime; Japanese additionally loads about 25 MB of Open JTalk frontend/dictionary assets. Output is mono 24 kHz.

Downloads start only on Generate. Text stays in this browser. Requires a current browser with WebAssembly SIMD. Cached downloads may be evicted; retry online after a cache miss.
