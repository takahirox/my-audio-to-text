Node Playground

Try each available processor node on its own test page, with inputs and outputs suited to that node.

  • Speech-to-Text (ReazonSpeech ja-en)

    Transcribe microphone or browser-tab audio locally. The SpeechToTextNode uses ReazonSpeech ja-en with Silero VAD and hayamimi-inspired processing, and displays provisional and final transcripts.

  • OPUS-MT Translation (Japanese → English)

    Translate text locally with a lightweight quantized OPUS-MT model in a dedicated WASM Worker.

  • OPUS-MT Translation (English → Japanese)

    Evaluate the independent English → Japanese production Node in its dedicated WASM Worker.

  • TranslateGemma 4B Translation (Japanese → English)

    Translate text locally with TranslateGemma 4B in a dedicated WebGPU Worker. Requires a supported GPU and a large model download.

  • Supertonic 3 Text-to-Speech

    Synthesize Japanese or English speech locally in a dedicated WASM Worker, with 44.1 kHz audio.

  • Kokoro 82M Text-to-Speech

    Synthesize Japanese or English speech locally with Kokoro and its language frontend in a dedicated WASM Worker, with 24 kHz audio.
