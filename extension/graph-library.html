    Help

    Graph choices apply to the next session. A running session keeps its graph.

    Choosing a graph does not enable website controls or grant permission. Turn ON to request website access.

    Website access & microphone help

    Enabling requests access to all HTTP and HTTPS websites (http://*/* and https://*/*) to place a mic beside supported text fields. Microphone capture starts only when you click the mic, in an extension recording window with a separate microphone permission. Audio is processed locally.

    Browser/internal pages, frames and sensitive fields are unsupported. Turn OFF to remove page controls and cancel recording; the graph assignment stays saved. To revoke website access, open Chrome → Extensions → Manage extensions → this extension → Details → Site access.

    Show microphone buttons on web pages?

    Allow access to all HTTP and HTTPS websites to show a mic beside supported text fields. Audio is processed locally; microphone capture starts only when you click the mic, with a separate microphone permission.

    Turn OFF here to stop and remove controls. Revoke website access in Chrome’s extension Site access settings.
