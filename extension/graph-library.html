    Web voice typing

    Help

    Enabling requests access to all HTTP and HTTPS websites (http://*/* and https://*/*) to place a mic beside supported text fields. Microphone capture starts only when you click the mic, in an extension recording window with a separate microphone permission. Audio is processed locally.

    Browser/internal pages, frames and sensitive fields are unsupported. Turn OFF to remove page controls and cancel recording; the graph assignment stays saved. To revoke website access, open Chrome → Extensions → Manage extensions → this extension → Details → Site access.
