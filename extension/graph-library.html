Website access & microphone help

Enabling requests access to all HTTP and HTTPS websites (http://*/* and https://*/*) to place a mic beside supported text fields. Click the page mic to start or stop local dictation in place. If microphone permission is needed, a one-time setup tab asks for Chrome’s native consent, then closes. Later recordings run without a visible recording window.

Browser/internal pages, frames and sensitive fields are unsupported. Turn OFF to remove page controls and cancel recording; the page-mic default stays saved. Right-click a page mic (or press Shift+F10 on it) to choose its default graph. To revoke website access, open Chrome → Extensions → Manage extensions → this extension → Details → Site access.
