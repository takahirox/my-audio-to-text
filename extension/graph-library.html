Enabling requests access to all HTTP and HTTPS websites (http://*/* and https://*/*) to place a mic beside supported text fields. Click the page mic to start or stop local dictation in place. Your current website requests Chrome’s native microphone permission when needed. Capture stays on that page and audio is sent locally to the extension’s graph; no setup tab or recording window opens. HTTPS (or localhost) and a site policy allowing microphone capture are required.

Browser/internal pages, frames and sensitive fields are unsupported. Turn OFF to remove page controls and cancel recording; the page-mic default stays saved. Right-click a page mic (or press Shift+F10 on it) to choose its default graph. To revoke website access, open Chrome → Extensions → Manage extensions → this extension → Details → Site access.
