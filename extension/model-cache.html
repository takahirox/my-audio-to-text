Chrome-profile storage

Verified cached assets can survive page recreation and Chrome restarts in this profile. Storage is best-effort: eviction, user deletion or uninstalling can remove it. Check before offline use. Closing the downloading page cancels preparation; retry keeps verified files.

Voice variants share weights in the existing cache. Deleting one variant removes shared files and may make other voices unavailable. Model preparation and deletion are coordinated across pages; stop recording before deleting a model it uses.

Persistence does not guarantee permanent retention. Downloads fetch pinned assets only; text and audio stay local. Supertonic weights/voices: OpenRAIL-M; Kokoro: Apache-2.0. TTS terms and notices · Matching eSpeak NG source / build bundle (GPL-3.0-or-later).

TranslateGemma is unavailable in the extension. The small #67 cache fixture is a test asset, not an installed translation or TTS model.
